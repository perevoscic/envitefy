# Football content art directions

All 90 designs have explicitly authored section, heading, card and navigation treatments with restrained CSS gradients. The editor and guest page use the same renderer. Shared editing controls remain separate from the designed sections.

Edit the recipes in `scripts/build-football-presentations.cjs`, then run that script to rebuild the CSS. Do not add SVG background patterns; the user requested their removal. Original hero artwork is preserved.
