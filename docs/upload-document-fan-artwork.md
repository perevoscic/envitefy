# Upload document fan artwork

The `/create` Upload empty state uses four original decorative source-document illustrations. These are examples only; their sample words, names, dates and schedules never become intake or event data. The adjacent HTML caption provides the accessible example names. The papers stay static and retain their original colors in light and dark appearance.

Generated with the built-in imagegen tool from the approved “01 / The document fan” desktop/mobile mockup. Each asset is a flat, full-bleed portrait paper, 1060 × 1484 pixels. FFmpeg `libwebp`, quality 85 and compression level 6, converted the original output to WebP without resizing; decoding was verified before deleting the corresponding temporary PNG and base64 copies.

## Shared prompt

Create one original flat printed source-document illustration for Envitefy’s decorative upload-example fan. Follow the corresponding paper’s art direction in the approved mockup. A portrait 5:7 paper completely fills the rectangular canvas edge to edge. Straight-on flat paper, no perspective or rotation, no external margin, desk, outside shadow, app chrome, board, watermark or rounded outer corners. CSS rotates and overlaps these papers. Use tasteful illustration and authentic printed typography, recognizable when small. All content is an illustrative sample, without real personal information or actual brands.

Load the artwork only when the Upload empty state mounts. Do not use these illustrative facts in created events or treat the papers as category buttons. File selection and dropping files continue through the existing validated source intake.
