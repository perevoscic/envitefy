# Football source import and hero controls

- File and public URL imports now prefill the current football editor without creating an event or storing a source asset. The selected design, custom hero and typography remain in place. Only explicit save/publish persists progress.
- Empty source fields stay blank on load and import. A season without a primary date/time no longer receives a demo kickoff. Chicago, Panthers Field, sample practices, equipment and bus logistics are not fallback event facts.
- URL fetching pins public DNS addresses, checks every redirect, limits response size/time, strips executable content and keeps readable tables, links and structured page data. Sources requiring login or client-only schedules may need a direct schedule/document URL.
- Game cards share one renderer for both teams, home/away/neutral status, available stadium/address, results, game calendar actions, directions, broadcast notes and tickets. Away locations do not inherit the home stadium. Empty cards and missing detail sections are omitted.
- Game Schedule exposes a Buy tickets URL for each matchup and a home-stadium name/address with Find tickets, stadiums & miles. Each card places Buy tickets beside Get directions and shows available one-way road mileage and drive time between the two stadiums. The same controls render on legacy football pages. Ticket imports keep each host's purchase link with its game and never substitute a home ticket portal for away games.
- Travel enrichment uses Google Routes first, matching the Google Maps directions destination, and Mapbox as a fallback. Both compare alternative routes by road distance, rather than accepting a large interstate detour because it is returned first. WeatherAPI supplies forecasts close to game day. Failed or unconfigured providers leave metrics absent; valid current results survive a temporary failure. Changed addresses/date/time invalidate displayed metrics; stale forecasts are hidden.
- A shared, labelled hero image editor supports replacement and restoring the template image across category editors. Existing wedding hero replacement remains available. Image selection is kept in memory, preserving the chosen image format and alpha, until the existing explicit save uploads it.
- Football mobile drawer closing no longer scrolls the canvas sideways or leaves hidden controls reachable. The import header stays in normal flow, and URL input retains focus while typing.
- Football section navigation now uses shared accessible tabs: only the selected panel occupies page space, with arrow/Home/End keyboard navigation and existing section hashes. Other panels remain mounted to preserve local input state. The editor and both public layouts share this behavior. South Walton's confirmed Seahawks identity is applied to generic school-name imports and kept consistent across headings, details and matchups; other mascots are used only when supported by the source.
