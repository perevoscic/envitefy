# Football thumbnail art direction

The marketing and designer reviews agreed that the existing artwork needed more room. Large name panels occupied roughly 45% of editorial and split cards, leaving shallow photo strips beside full-image cinematic designs.

The revised presentation gives editorial and split artwork approximately 72% of a card when its title fits, with room for names to wrap on narrow screens. Poster designs keep centered titles and an inset image. Cinematic designs keep full-image artwork, with a gradient concentrated behind the name. Every design retains its existing palette, typeface and WebP asset. The main football, team huddle and player photographs have deliberate focal positions.

Titles now size against the card width rather than the browser width. Compact editor previews use the same compositions with their own readable type scale. Shared white shells, stable varied masonry heights, four desktop columns, two mobile columns, accessible selection controls and automatic loading remain in place.

The opening collection mixes team spirit, heritage, field photography and stadium energy before the more specialized graphic styles. This is a merchandising judgment, not a measured conversion result. The gallery and editor picker share the presentation order; the underlying registry, default design and all 37 IDs remain intact. CSS columns flow downward and rebalance as additional batches load, so a fixed left-to-right opening row is not promised.

Validation: inspected the live desktop gallery, 375px mobile gallery, long-title search result and compact editor picker. All 37 mobile cards remain reachable without horizontal overflow or titles extending outside their cards. Existing artwork/theme, uploaded-image preservation and palette contrast tests pass. Focused TypeScript and Biome checks pass. The VS Code diagnostics command could not run because no Chat to CLI linter bridge was available.
