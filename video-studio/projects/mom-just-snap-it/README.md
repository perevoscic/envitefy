# Envitefy — Mom, Just Snap It!

One shared 35-second / 1050-frame timeline, two responsive layouts.

- EnvitefySnapAnimeWide: 1920 × 1080 at 30 fps.
- EnvitefySnapAnimeVertical: 1080 × 1920 at 30 fps.

Editable scene and layout: ../../src/mom-just-snap-it/SnapAnime.tsx
Shared source library: ../../public/projects/mom-just-snap-it/
Outputs and review media: ../../out/mom-just-snap-it/

Run npm run dev from video-studio, then select either composition. Run node scripts/render-snap-anime-final.mjs to export both with one identical encoded soundtrack. See production-notes.md for source selection, workflow proof, limitations and pending pronunciation review.
